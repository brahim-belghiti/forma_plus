# forma+

**forma+** is a web-based management platform for training centers. It centralizes student enrollment, teacher management, scheduling, payments, and expenses into a single fast application.

## Features

- **Students** — enrollment, level assignment, group management
- **Teachers** — profile, subjects taught, salary tracking
- **Classrooms** — room setup and capacity
- **Sessions & Schedules** — class sessions, time slots, attendance tracking
- **Payments** — record fees, track unpaid students, generate receipts
- **Expenses** — log and manage center expenses
- **Personnel** — non-teaching staff management
- **Dashboard** — activity overview, financial summary, unpaid student alerts
- **Authentication** — secure login with 2FA support, password reset, email verification

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Laravel 13 (PHP 8.5) |
| Frontend | React 19 + TypeScript |
| SPA Bridge | Inertia.js v3 |
| Styling | Tailwind CSS v4 |
| Auth | Laravel Fortify v1 |
| Routing (typed) | Laravel Wayfinder |
| Testing | Pest v4 |
| Build | Vite 8 |

## Requirements

- PHP 8.5+
- Node.js 20+
- Composer
- A supported database (MySQL, PostgreSQL, SQLite)

## Getting Started

```bash
# Clone the repository
git clone <repository-url>
cd school

# Install PHP dependencies
composer install

# Install Node dependencies
npm install

# Copy environment file and generate app key
cp .env.example .env
php artisan key:generate

# Configure your database in .env, then run migrations and seeders
php artisan migrate --seed

# Start the development server
composer run dev
```

The app will be available at `http://localhost:8000`.

## Running Tests

```bash
php artisan test
```

## Architecture Notes

- Pages live in `resources/js/pages/` and are rendered server-side via `Inertia::render()`.
- Typed route functions are auto-generated by Wayfinder into `resources/js/actions/` and `resources/js/routes/` — run `php artisan wayfinder:generate` after adding or changing routes.
- Authentication is handled entirely by Laravel Fortify; user accounts are created by administrators, not through public registration.
